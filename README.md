# Geometric Quantum Machine Learning
Implementation of Equivariant Quantum Neural Networks (EQNNs) for analyzing game configurations and comparing their performance with conventional Quantum Neural Networks (QNNs). This project explores how symmetry-preserving quantum architectures can improve learning efficiency, generalization, and accuracy in structured game environments.
## Project overview
The script performs the following steps:

1. Preprocesses and encodes game configuration data into quantum-compatible representations
2. Constructs parameterized quantum circuits for both standard QNNs and Equivariant Quantum Neural Networks (EQNNs)
3. Implements symmetry-preserving operations within the equivariant quantum architecture
4. Trains the quantum models using a hybrid quantum-classical optimization framework
5. Evaluates model performance on classification and prediction tasks
6. Compares EQNNs and conventional QNNs based on accuracy, convergence, and generalization capability
7. Visualizes training metrics, loss behavior, and quantum feature representations
8. Analyzes the impact of geometric symmetries on quantum learning performance
## Requirements
1. Python 3.9 or higher
2. PennyLane
3. PyTorch
4. NumPy
## Results
The output of the simulation is a comparative analysis between the Equivariant Quantum Neural Network (EQNN) and the conventional Quantum Neural Network (QNN) for classification of game configurations. The comparison is performed using metrics such as classification accuracy, convergence rate, loss reduction, and generalization capability.

The results demonstrate how symmetry-preserving quantum architectures influence learning performance and whether incorporating equivariant principles improves efficiency and robustness compared to standard quantum neural network models.
